# MED-REMAINDER APP

# Project Overviewer:

Medication Reminder App is a simple web-based application developed to help users, especially elderly people, remember their medicine schedules on time. The application allows users to add medicine details, dosage timing, and reminders for daily medication tracking.The project is developed using HTML, CSS, and JavaScript with a user-friendly interface for easy usage.

# Features:

1.Add medicine details.

2.Set reminder time for tablets.

3.View medicine schedule.

4.Daily medication tracking.

5.Simple and responsive user interface.

6.Easy-to-use reminder management.

# Technologies Used:

HTML	- Structure of the application.
CSS	- Styling and responsive design.
JavaScript -	Functionality and reminder logic.

# Project Modules:

1.Allows users to add and manage medicine details.

2.Stores reminder timings for medicines.

3.Displays daily medicine schedules.

4.Provides a clean and simple design for elderly users.
